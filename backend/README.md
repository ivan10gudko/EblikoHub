# EblikoHub Backend

Інструкція для швидкого запуску бекенд-сервісу локально через Docker.

## 📋 Вимоги

Перед запуском переконайся, що у тебе встановлено:

- [Docker](https://www.docker.com/) та запущений **Docker Desktop**.
- Обов'язково наявність файлу `.env` у цій же папці з необхідними змінними середовища.

---

## 🚀 Як запустити проєкт

### Для Windows (найпростіший спосіб):

Просто двічі клікни на файл **`run.bat`** у цій папці або виконай у терміналі:

```cmd
.\run.bat
