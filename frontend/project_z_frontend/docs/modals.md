# Архітектура та конфігурація маршрутизації модалок

Документ описує роботу з модальними вікнами через нативні вкладені маршрути (Nested Routes) за допомогою централізованої конфігурації.

## Огляд
Проєкт працює згідно парадигми нативної маршрутизації.

**Кожна модалка — це окремий файл маршруту (наприклад, `title.edit.tsx`, `room.title.links.tsx`), зареєстрований як дочірній маршрут у routes.ts з унікальним ідентифікатором. Відкриття модалки тепер є стандартною навігацією; роутер декларативно керує монтуванням та розмонтуванням компонентів.**

## Шар конфігурації
Щоб уникнути зайвого коду (бойлерплейту) та захаращення основного файлу роутингу ручними оголошеннями route(...), усі визначення модалок зосереджені в єдиному конфігураційному файлі:

- `app/routes/modals/routes.config.ts`

У цьому файлі модалки структуровані у вигляді типізованих мап (`titleModals`, `roomTitleModals`, `adminModals`), що відповідають `Record<string, ModalRouteDef>`, зіставляючи конкретні ключі з конфігураціями шляхів (`path`) та файлів (`file`).

## API та використання
Функції-помічники (такі як `titleModalRoutes, roomTitleModalRoutes, adminModalRoutes`) використовують утиліту `pickModals` для динамічного витягування всього набору маршрутів або їх відфільтрованого підмножини.

TypeScript
```
// 1. Зареєструвати всі модалки в межах доменної групи
titleModalRoutes("watchlist");

// 2. Зареєструвати тільки вибрані модалки за допомогою ясного списку ключів
titleModalRoutes("anime", ["edit", "view", "rating", "seasons"]);
```

> Примітка: Другий аргумент (keys) є опціональним. Якщо його пропустити, функція поверне повну мапу вказаної групи.

## Робочий процес розробника
### Додавання модалки до існуючої групи
Ручний виклик `route()` всередині `routes.ts` більше не потрібен. Щоб додати нову модалку:
  1. Створіть відповідний файл компонента маршруту.
  2. Зареєструйте новий елемент (шлях та посилання на файл) у відповідній мапі всередині `app/routes/modals/routes.config.ts`.

### Створення нової доменної групи модалок
Для впровадження абсолютно нового набору модалок:

1. Визначте нову мапу в `app/routes/modals/routes.config.ts`, використовуючи конструкцію `satisfies Record<string, ModalRouteDef>`.
2. Експортуйте функцію-обгортку за допомогою вбудованої утиліти `pickModals` у тому ж файлі.
